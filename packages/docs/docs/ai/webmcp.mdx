# WebMCP<AvailableFrom v="4.0.518" />

Remotion Studio exposes WebMCP tools that allow an AI agent to inspect and steer it.

## Capabilities

Agents can:

- See which items you currently have selected
- See selectable items and select them
- Duplicate sequences and inspect duplication progress
- See available compositions and navigate to them
- Read the error currently shown in the Studio error overlay
- Get the current HTML of your composition
- See current outlines of elements and their geometry
- Get your current playhead position and playback state
- Play, pause and seek
- Set timeline zoom, playback rate, looping, and mute state
- See, add and remove guides
- Install packages into the current project
- Transcribe audio and video assets
- Remove the background from video assets
- Restart or shut down the Studio server

## Requirements

Start the [Remotion Studio](/docs/studio) and open it in a browser with an AI agent that supports [WebMCP](https://webmcp.dev/).

## Compatible agents

Out of the major harnesses, only ChatGPT Codex supports WebMCP. We hope more agents add support soon.

## Available tools

:::note

The shape of inputs and outputs is not currently stable.

:::

Tools that edit sequences or guides require a composition to be open.
Playback tools work with compositions and, from <AvailableFrom v="4.0.540" inline />, audio and video asset previews after their metadata loads. Images, text files and rendered-output previews are not supported by playback tools.

Playback tools run locally in all four Studio modes: regular, detached, read-only deployed and Browser Studio. They require a ready preview, not an attached Studio server.

### `install_package`<AvailableFrom v="4.0.523" />

Installs an npm package into the current Remotion project. Remotion packages use the current Remotion version. Auxiliary packages such as `@huggingface/transformers` use Remotion's recommended version.

```ts title="Input"
{
  packageName: string;
  version?: string;
}
```

`version` must be an exact semantic version when specified.

```ts title="Output"
{
  installed: true;
  packageName: string;
}
```

### `transcribe_asset`<AvailableFrom v="4.0.523" />

Transcribes an audio or video asset from the `public/` folder and adds the work to the Jobs queue. The output is a JSON file containing a [`Caption[]`](/docs/captions/caption) array.

If `assetPath` is omitted, the asset currently open in the Studio is used.

```ts title="Input"
{
  assetPath?: string;
  outputPath?: string;
  model?: string;
  language?: string;
  task?: 'transcribe' | 'translate';
  chunkLengthInSeconds?: number;
  strideLengthInSeconds?: number;
  forceFullSequences?: boolean;
  doSample?: boolean;
  temperature?: number;
  topK?: number;
  repetitionPenalty?: number;
  noRepeatNgramSize?: number;
}
```

The default model is `small.en`. The default output is `<asset>-captions.json`. See [`transcribe()`](/docs/whisper-webgpu/transcribe) for the Whisper options and their defaults.

```ts title="Output"
{
  success: true;
  jobId: string;
  outputPath: string;
}
```

The job continues in the background and can be followed in the Jobs panel.

This tool is always exposed. If `@remotion/whisper-webgpu` is not installed, it returns:

```ts title="Missing package output"
{
  success: false;
  error: string;
  installPackage: {
    tool: 'install_package';
    packageName: '@remotion/whisper-webgpu';
  }
}
```

Call `install_package` with the returned package name and retry. Studio also installs the recommended `@huggingface/transformers` version.

### `remove_video_background`<AvailableFrom v="4.0.523" />

Removes a video asset's background and saves a transparent WebM file in the `public/` folder. The work is added to the Jobs queue.

```ts title="Input"

  outputPath?: string;
  model?: string;
```

The default model is `ben2-base`, the input audio is kept, and video quality defaults to `very-high`. The output name defaults to `<asset>-no-background.webm`.

```ts title="Output"
  outputPath: string;
```

This tool is always exposed. If `@remotion/video-matting` is not installed, it returns:

### `get_sequences`

Returns the timeline sequences mounted for the current composition, including their hierarchy, timing, effects, source stack and selection support.

```ts title="Input"
{
}
```

```ts title="Output"
{
  currentContent: CurrentContent | null;
  pendingDuplications: Array<{
    absolutePath: string;
    nodePath: Array<string | number>;
  }>;
  pendingEffectDeletions: Array<{
    absolutePath: string;
    nodePath: Array<string | number>;
    effectIndices: number[];
  }>;
  sequences: Array<{
    sequenceId: string;
    name: string | null;
    type: 'sequence' | 'audio' | 'video' | 'image';
    parentSequenceId: string | null;
    depth: number;
    startFrame: number;
    endFrame: number;
    durationInFrames: number;
    stack: string | null;
    selectable: boolean;
    duplicating: boolean;
    effects: Array<{
      effectIndex: number;
      type: string;
      label: string;
      canDelete: boolean;
      deleting: boolean;
    }>;
  }>;
}
```

#### `sequences[].duplicating`<AvailableFrom v="4.0.540" />

Whether a duplication of this sequence's source node is pending. This includes duplications started through the Studio interface or `duplicate_sequence`.

#### `pendingDuplications`<AvailableFrom v="4.0.540" />

Source nodes with a pending duplication in the current Studio tab, including nodes that are temporarily unmounted during a preview refresh. An empty array reports no pending source nodes; it does not mean the preview has finished refreshing.

##### `absolutePath`

The absolute path of the source file.

##### `nodePath`

The path to the JSX node within that source file, represented as an array of strings and numbers.

#### `sequences[].effects`<AvailableFrom v="4.0.540" />

The sequence's mounted effects in their current order. Available in all Studio modes; deletion requires source editing.

##### `effectIndex`

The zero-based position in the effect chain. Use this with `sequenceId` when calling `delete_effect`. Read the effects again after deleting, adding, or reordering an effect because indices can change.

##### `type`

The effect definition's type identifier. Multiple effects can have the same type.

##### `label`

The effect's display name in Studio.

##### `canDelete`

Whether the current mode and source allow deletion. This is `false` while any deletion of the same source node's effects is pending.

##### `deleting`

Whether this mounted effect is included in a pending deletion started through Studio or `delete_effect`. After the preview refreshes with the updated chain, this is `false` for the remaining effects, even if the save response is still pending.

#### `pendingEffectDeletions`<AvailableFrom v="4.0.540" />

Pending effect deletions in the current Studio tab, including source nodes that are temporarily unmounted during a preview refresh.

##### `absolutePath`

The absolute path of the source file.

##### `nodePath`

The path to the JSX node within that source file, represented as an array of strings and numbers.

##### `effectIndices`

The zero-based effect indices in the chain before the deletion started. These indices do not refer to the remaining effects after the preview refreshes.

### `delete_effect`<AvailableFrom v="4.0.540" />

Deletes an effect using the same action as the Studio interface. The preview updates optimistically; a failed deletion restores the effect.

Requires a composition to be open and editable effect source in a connected interactive Studio or Browser Studio. Unavailable when the preview server is detached or the Studio is deployed as read-only. Deleting an effect edits the source and affects every runtime instance of that JSX node.

```ts title="Input"
{
  sequenceId: string;
  effectIndex: number;
}
```

#### `sequenceId`

Required. The ID of a sequence returned by `get_sequences`.

#### `effectIndex`

Required. A non-negative integer from the sequence's current `effects` list in `get_sequences`.

```ts title="Output"
{sequenceId: string; effectIndex: number} & (
  | {status: 'success'}
  | {status: 'already-pending'}
  | {status: 'error'; reason: string}
)
```

#### `status`

`success` means the deletion was saved to source. The preview may still be refreshing.

`already-pending` means an effect deletion for the same source node is already in progress. No additional deletion was requested.

`error` means deletion failed. Invalid inputs, unavailable effect editing, and missing sequences or effects reject the tool call before deletion starts.

#### `reason`

The failure message, present when `status` is `error`.

### `duplicate_sequence`<AvailableFrom v="4.0.540" />

Duplicates the source JSX node for a sequence using the same action as the Studio inspector.

Studio selects the copied sequence roots once they are available in the preview. Changing the selection or switching away from the composition while duplication is pending prevents this automatic selection. If overlapping source refreshes make the copied nodes ambiguous, Studio preserves the current selection; select a copy after the preview finishes updating.

A clip directly inside a [`<Track>`](/docs/track), including through anonymous fragments, is copied into a separate sibling track with its timing preserved. If an intervening element or expression prevents this, duplicate the enclosing track instead.

Requires a composition to be open and source editing to be available in a connected interactive Studio or Browser Studio. Unavailable when the preview server is detached or the Studio is deployed as read-only. Transitions and sequences whose source is unavailable cannot be duplicated.

```ts title="Input"
{
  sequenceId: string;
  confirmProgrammaticDuplication: boolean;
}
```

#### `sequenceId`

Required. The ID of a sequence returned by `get_sequences`.

#### `confirmProgrammaticDuplication`

Required. When one source node produces multiple runtime instances, copying it creates a copy for every instance. Set `true` to confirm this behavior. Set `false` to cancel duplication of programmatically repeated nodes. A single-instance node is duplicated with either value.

```ts title="Output"
{sequenceId: string} & (
  | {status: 'success'}
  | {status: 'already-pending'}
  | {status: 'cancelled'}
  | {status: 'error'; reason: string}
)
```

#### `status`

`success` means the source copy was saved. The preview may still be refreshing; new sequence IDs appear in `get_sequences` afterward.

`already-pending` means a duplication of this source node is already in progress. No additional copy was requested.

`cancelled` means no copy was requested, for example because a programmatically repeated node was not confirmed.

`error` means duplication failed. Invalid inputs, unavailable source editing, and missing or unsupported sequences reject the tool call before duplication starts.

#### `reason`

The failure message, present when `status` is `error`.

## Example prompts

You can ask a browser agent:

- "What is currently selected in the Studio?"
- "Fix the error"
- "List all mounted compositions and their folders."
- "Open the `Shapes` composition."
- "List the sequences and select the `Title` sequence."
- "Duplicate the `Title` sequence."
- "Inspect the HTML rendered on the canvas."
- "List the visible components and their canvas geometry."
- "What is the current playback state?"
- "Set the timeline zoom to 0.5."
- "Seek to frame 90, set the playback rate to 0.5x and play."
- "List the guides in the current composition."
- "Hide the guides."
- "Add a vertical guide at 640 pixels."
- "Mute the preview."
- "Turn off looping for the audio asset preview."
- "Transcribe the audio asset that is currently open."
- "Remove the background from `product-shot.mp4`."

The agent chooses and invokes the matching tools. Tool calls affect the open Studio tab immediately.
